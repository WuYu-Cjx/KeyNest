================================================================
键巢（KeyNest）第三方组件与许可证清单
================================================================
适用范围：键巢主程序、安装器、卸载器（运行时）
更新日期：2026-11-17

一、运行时组件
----------------------------------------------------------------
1) .NET 8 Runtime / Windows Desktop Runtime
   名称：Microsoft .NET Runtime（含 WPF、Windows Forms 组件）
   版本：8.0.x
   许可证：MIT
   用途：应用运行时、WPF 界面、WinForms NotifyIcon 托盘图标
   是否可商用：是
   需保留声明：是（随运行时自带的 LICENSE.txt 保留）
   备注：安装包以自包含方式发布，运行时随安装包一同分发，不联网下载。

2) Windows 公开 API（user32.dll / kernel32.dll / dwmapi.dll / shell32 等）
   名称：Microsoft Windows 操作系统组件
   版本：随操作系统
   许可证：系统组件，适用 Windows 许可条款
   用途：低级键盘钩子、窗口扩展样式、DWM 圆角、Shell 快捷方式、注册表
   是否可商用：是（作为系统 API 调用）
   需保留声明：否（不复制任何系统文件）

3) Microsoft.Win32.Registry（.NET 类库）
   许可证：MIT
   用途：读取系统主题、写入开机自启与卸载信息
   是否可商用：是
   需保留声明：是（随 .NET 许可证）

三、明确未使用的组件类别
----------------------------------------------------------------
· 未使用任何 GPL / AGPL / LGPL 组件。
· 未使用任何来源不明、逆向或破解代码。
· 未使用 Windows 系统图标、Office 图标或第三方商业图标库。
· 未打包任何第三方字体；界面仅使用系统自带 Segoe UI / Segoe UI Variable。
· 未引入遥测、崩溃上报、广告或网络请求组件。
· 未使用任何已知专利受限算法；匹配逻辑为自研的位掩码集合包含关系。

四、图标与视觉资产
----------------------------------------------------------------
键巢的品牌图标、悬浮窗图形、按钮与开关样式均为本项目原创，
通过 XAML 矢量图形与 GDI+ 运行时绘制生成，不使用任何外部图片资源。

五、许可证保留方式
----------------------------------------------------------------
· 发布包安装目录内保留本文件（THIRD-PARTY-NOTICES.txt）与 PRIVACY.txt。
· .NET 运行时的 MIT 许可证文本随自包含发布目录一并分发。
· 测试组件的许可证文本保留在源码仓库的包缓存与项目引用中，不进入发布包。
· 如需再分发，请保留上述声明与许可证文本；不得移除产品名称与版权声明。

六、发布前检查建议
----------------------------------------------------------------
1. 执行 build\test.ps1，确认单元测试全部通过。
2. 核对本清单与实际发布的依赖（dotnet list package --include-transitive）。
3. 如后续引入新组件，必须确认许可证为 MIT / Apache-2.0 / BSD 等宽松许可，
   并同步更新本文件。
4. 建议由法务或合规负责人完成一次许可证与专利风险评估。
