================================================================
键巢（KeyNest）隐私说明
================================================================
生效日期：2026-11-17

一、总则
----------------------------------------------------------------
键巢是一个完全本地运行的 Windows 桌面工具。我们不运营任何服务器，
也不提供账号体系。使用键巢不需要登录，不需要联网。

二、我们不收集什么
----------------------------------------------------------------
· 不收集、不记录、不上传任何按键历史。
· 不收集、不保存任何输入内容（包括剪贴板、文本、密码）。
· 不收集设备标识、位置、使用统计或崩溃报告。
· 不进行任何形式的用户画像、广告投放或行为分析。
· 不发起任何网络连接（包括更新检查）。

三、键盘钩子的用途
----------------------------------------------------------------
启用监听后，程序使用 Windows 公开 API 安装 WH_KEYBOARD_LL 低级键盘钩子，
仅用于判断“当前按下了哪些修饰键（Ctrl / Shift / Alt / Win）”。

· 钩子回调中不读取、不保存任何字符内容。
· 回调中不写入磁盘、不发送网络请求。
· 默认不拦截任何按键；所有按键都会继续传递给系统。
· 仅当用户主动开启“接管单按 Win”时，才会拦截单按 Win 的抬起事件，
  该设置默认关闭，可随时在设置中关闭。
· 停用监听或退出程序时，钩子会被立即卸载。

四、本机保存的数据
----------------------------------------------------------------
路径：%APPDATA%\KeyNest\settings.json

字段：
· theme               主题选择（跟随系统 / 浅色 / 深色）
· autoStart           是否开机自启
· floating.opacity    悬浮窗不透明度
· floating.takeoverSingleWin 是否接管单按 Win
· floating.includeNoModifierKeys 是否在悬浮窗中补充显示无修饰键单键
· position            悬浮窗位置
· privacyNoticeShown  隐私提示是否已展示

路径：%APPDATA%\KeyNest\keynest.log
内容：仅程序启动/退出、钩子安装/卸载、配置读写失败等运行事件。
日志不包含按键序列、不包含输入文本、不包含任何个人信息。

上述数据全部只保存在本机，不会上传。删除方式：
· 在设置中点击“打开配置目录”后手动删除；
· 卸载时取消勾选“保留用户配置”；
· 或直接删除 %APPDATA%\KeyNest 目录。

五、开机自启
----------------------------------------------------------------
若用户开启开机自启，程序会写入：
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
值名：KeyNest
值：  "<安装目录>\KeyNest.App.exe" --tray

该值仅用于启动键巢，不涉及任何数据收集。关闭开关或卸载时会被删除。

六、第三方组件
----------------------------------------------------------------
键巢仅使用 .NET 8 运行时与 Windows 公开 API，不包含 GPL/AGPL 组件。
完整清单见同目录下的 THIRD-PARTY-NOTICES.txt。

七、儿童隐私
----------------------------------------------------------------
键巢不面向儿童设计，也不收集任何年龄或身份信息。

八、变更与联系
----------------------------------------------------------------
如本说明发生变更，将随新版本一起发布并在安装目录中更新本文件。
